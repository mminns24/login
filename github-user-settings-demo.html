User Login Demo

Create a test account, choose some settings, refresh the page, log out, or create another account. Each username gets its own saved choices.

Demo only: usernames and passwords are stored in this browser's localStorage. Do not use real passwords. A production version would use Supabase, Firebase, Auth0, etc.

How to Test It

Make some changes, then refresh the browser. Your choices should remain. Next, log out and create another username. That second user will get a separate set of settings. Log back into the first account and its old choices will return.
